# Оптимізація Google Ads Neuronix: посадкові сторінки, розширення, RSA

> **Для агентів-виконавців:** виконувати через `superpowers:executing-plans` або `superpowers:subagent-driven-development`, задача за задачею. Кроки — чекбокси `- [ ]`.

**Мета:** підняти post-click Quality Score з BELOW_AVERAGE до AVERAGE+ у всіх ключах кампанії `24138448702`, відвоювати частину з 52,5% показів, втрачених через Ad Rank, і знизити CPC з 53,41 грн.

**Архітектура:** три нові посадкові сторінки будуються на **існуючому** маршруті `src/app/[locale]/[platform]/page.tsx` — він уже приймає namespace і збирає сторінку з готових компонентів. Нового коду компонентів немає: додаються значення в масив `PLATFORMS` і гілки в `src/i18n/{uk,en}.json`. Ads-частина (розширення, RSA, phone_click) не залежить від сайту і виконується першою.

**Стек:** Next.js 15 App Router + next-intl (JSON-повідомлення), Vercel; Google Ads API v23 через AdLoop MCP; GTM + GA4 (`properties/548742185`).

**Вихідні дані:** заміри 25.08.2026 за період 14–25.08.2026 (12 днів — уся історія акаунта). 500 показів, 39 кліків, 2 082,92 грн, CTR 7,8%, CPC 53,41 грн, 2 конверсії Ads / 4 дії all_conversions. Деталі — у розділі «Чому саме ці задачі» в кінці.

## Глобальні обмеження

- **Акаунт:** Google Ads `9087037980` (Neuronix), кампанія `24138448702` `Search — Сайти та магазини (UA)`, бюджет 200 грн/день, стратегія `TARGET_SPEND`.
- **Ставки й стратегію НЕ чіпати.** Кампанії 12 днів, вона в learning. Перехід на tCPA — не раніше 15–30 конверсій/міс.
- **Кожна write-операція в Ads:** `draft_*` → показати preview Андрію → чекати явне «Apply» → `confirm_and_apply(dry_run=false)`. Без винятків.
- **Після кожного запису в Ads — перечитати стан GAQL-запитом і звірити з очікуваним.** Відповідь API `updated: 1` не є доказом, що значення збереглося.
- **Деплой сайту — тільки `git push` у `main`.** Vercel деплоїть сам. Ніяких `vercel deploy` з локалки.
- **Тестів у репозиторії немає.** Перевірка коду = `npm run build` (exit 0) + `npm run lint` + HTTP 200 на новому URL у проді.
- **Ліміти Google Ads:** заголовок RSA ≤ 30 символів, опис ≤ 90, callout ≤ 25, значення structured snippet ≤ 25.
- Мова інтерфейсу і контенту — українська та англійська (обидві гілки `uk.json` і `en.json` оновлюються разом, інакше `en`-сторінка впаде на відсутньому ключі).
