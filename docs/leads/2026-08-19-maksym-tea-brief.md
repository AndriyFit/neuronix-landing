## Як заповнювати

Блок A — **обов'язковий**, без нього оцінка неможлива (15 хв на заповнення).
Блок B — деталі, можна дозаповнити на дзвінку.
Якщо на питання немає відповіді — пишіть «не знаю» / «ще не вирішив». Це теж інформація.

# БЛОК A — критично для оцінки

## A1. Бізнес зараз

1. Скільки років працюєте, які основні канали продажу сьогодні (опт / роздріб / маркетплейси / соцмережі)?
2. Приблизна частка обороту: роздріб ___ % / опт-дропшип ___ %.
3. Скільки замовлень на місяць зараз: роздріб ___ / від дропшиперів ___.
4. Чи є діючий сайт? Посилання: ____________. Що конкретно в ньому не влаштовує?
5. Хто обробляє замовлення (скільки людей, у чому працюють — Excel, CRM, зошит)?

## A2. Асортимент

6. Кількість товарних позицій (SKU) зараз: ____ і план на 12 міс: ____.
7. Чай продається у фасуванні чи на вагу? Перелічіть фасування (напр. 50/100/250/500 г, кг).
   - Одна позиція має кілька фасувань з різними цінами? **Так / Ні**
8. Чи є, крім чаю: посуд, аксесуари, подарункові набори, кава? Перелічіть категорії.
9. Чи важливий облік партій і термінів придатності на сайті? **Так / Ні**
10. Де зараз лежить актуальний прайс і залишки (Excel, Google Sheets, 1С/BAS, CRM, ніде)?
    - Можете надіслати вивантаження прикладу? **Так / Ні**

## A3. B2B / дропшип — головна частина

11. Скільки зараз партнерів-дропшиперів: ____ . План на рік: ____ .
12. **Як вони працюють з вами СЬОГОДНІ?** Опишіть покроково: як дізнаються ціну, як бачать залишок, як передають замовлення, як дізнаються про відправку.
13. Ціноутворення для партнерів:
    - Одна оптова ціна для всіх / кілька рівнів залежно від обсягу / індивідуальна ціна під кожного партнера (потрібне підкреслити).
    - Скільки рівнів цін загалом: ____
14. Що партнер має бачити в кабінеті (позначте потрібне):
    - [ ] свій прайс і залишки в реальному часі
    - [ ] оформлення замовлення на кінцевого клієнта (ПІБ, телефон, адреса відділення)
    - [ ] своя націнка / сума до сплати клієнтом
    - [ ] статус замовлення і номер ТТН
    - [ ] історія своїх замовлень
    - [ ] взаєморозрахунки: скільки я винен / скільки мені винні
    - [ ] баланс або депозит, кредитний ліміт
    - [ ] вивантаження прайсу (XML/XLS) для заливки на Rozetka/Prom
    - [ ] маркетингові матеріали (фото, описи) для завантаження
15. **Хто формує ТТН Нової Пошти** — ви чи дропшипер? Від чийого імені йде відправка (ваше ФОП чи партнера)?
16. Оплата від кінцевого клієнта: накладений платіж / передоплата на партнера / передоплата на вас? Як потім розраховуєтесь з партнером і як часто?
17. Реєстрація нового партнера: вільна / з ручним підтвердженням / тільки за договором?

### A4.1 CRM

18. Чи використовуєте CRM зараз? **Так / Ні**
    - Якщо так: яка саме (KeyCRM, SalesDrive, Bitrix24, HubSpot, Perfectum, інша) ____________
    - Тариф і кількість користувачів: ____________
19. Хто адміністратор CRM з вашого боку (ім'я, контакт)? Чи зможе він надати API-ключ і доступ адміністратора?
20. Якщо CRM немає — плануєте впроваджувати разом із сайтом чи залишаєте обробку вручну?
21. **Що сайт має передавати в CRM** (позначте):
    - [ ] нове замовлення (склад, кількість, сума)
    - [ ] дані клієнта (ПІБ, телефон, email)
    - [ ] адреса доставки / відділення
    - [ ] спосіб оплати і статус оплати
    - [ ] коментар клієнта
    - [ ] джерело трафіку / UTM-мітки
    - [ ] позначка «замовлення від дропшипера» + який саме партнер
    - [ ] промокод / знижка
22. **Що сайт має забирати з CRM** (позначте):
    - [ ] статус замовлення (в обробці / відправлено / виконано / скасовано)
    - [ ] номер ТТН і посилання на трекінг
    - [ ] факт оплати
    - [ ] залишки товарів
    - [ ] ціни
    - [ ] нові товари
23. Обмін односторонній (сайт → CRM) чи двосторонній? Як часто: реальний час / кожні 15 хв / раз на добу?
24. Чи вже налаштовані у вас воронки й статуси в CRM, чи їх треба проєктувати з нуля?
25. Роздрібні й дропшип-замовлення йдуть в одну воронку чи в різні?

### A4.2 Облікова система (1С / BAS / Диловод / інше)

### A4.3 Доставка

34. Типи відправлень: відділення ☐ поштомат ☐ адресна доставка ☐ міжнародна ☐

36. Хто платить за доставку: клієнт / ви / залежить від суми замовлення?
37. Чи потрібне автоматичне оновлення статусу посилки на сайті й в кабінеті партнера?

### A4.4 Оплата

38. Способи оплати, які потрібні: накладений платіж ☐ картка онлайн ☐ рахунок для юросіб ☐ переказ на картку ☐ оплата з балансу партнера ☐
39. Еквайринг: LiqPay / WayForPay / Fondy / Mono / Portmone / ще не обрано. Чи є вже підписаний договір?

### A4.6 Маркетплейси й зовнішні майданчики

# БЛОК B — деталі (можна на дзвінку)

## B1. Дизайн і контент

64. Чи є логотип, брендбук, фірмові кольори? Надішліть файли.

## Що ми надішлемо після заповнення

- Порівняння Хорошоп vs OpenCart **під ваші конкретні вимоги** — не абстрактне, а по пунктах з цього брифу.
- Кошторис з розбивкою по блоках (базовий магазин / B2B-кабінет / кожна інтеграція окремо).
- Строки по етапах.
- Що входить у супровід після запуску.
